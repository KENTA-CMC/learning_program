PDF Link Highlighter - デプロイメントガイド
================================================

このフォルダには PDF Link Highlighter アプリケーションのデプロイメント用ファイルが含まれています。

前提条件:
--------
- Python 3.11以上がインストールされていること
- インターネット接続（初回セットアップ時に依存パッケージをダウンロードするため）

デプロイメント手順:
-----------------
1. このフォルダ全体を社内サーバーの以下の場所にコピーしてください：
   \\172.28.1.7\ms東京事業部\2R_OM\101_TOOLS\PDF Highlighter

2. コピー後、以下のいずれかの方法でアプリケーションを起動してください：

   方法A: start.batファイルを使用（推奨）
   - start.bat をダブルクリックして実行
   - 自動的に仮想環境の作成、依存パッケージのインストール、アプリの起動が行われます

   方法B: 手動セットアップ
   - コマンドプロンプトでこのフォルダに移動
   - python -m venv venv
   - venv\Scripts\activate
   - pip install -r requirements.txt
   - streamlit run app_streamlit.py --server.port 8502 --server.address 0.0.0.0

3. アプリケーションが起動したら、ブラウザで以下のURLにアクセスしてください：
   http://localhost:8502
   または
   http://[サーバーのIPアドレス]:8502

機能:
----
- PDFファイルのアップロード
- リンク領域の自動検出とハイライト
- ハイライト済みPDFのダウンロード

トラブルシューティング:
--------------------
- Pythonがインストールされていない場合：Python 3.11以上をインストールしてください
- ポート8502が使用中の場合：start.batファイル内のポート番号を変更してください
- 依存パッケージのインストールでエラーが発生する場合：インターネット接続を確認してください

サポート:
--------
問題が発生した場合は、システム管理者にお問い合わせください。
